# Black Mountain Entertainment Website

Static website deployment package for Render.

## Files
- `index.html` — website homepage
- `assets/bme-logo.jpeg` — company logo asset

## Render settings
- Service type: Static Site
- Build command: leave blank
- Publish directory: `.`

The website's current editing controls store browser-local data; they do not provide a shared online CMS. Uploaded trailers and other media added through the editor are stored in that browser unless separately hosted and configured.
